## 📧 EmailJS Setup (Contact Form)

To make the contact form work on your own fork:

### Step 1: Create EmailJS Account
Sign up at [emailjs.com](https://www.emailjs.com/)

### Step 2: Add Email Service
- Dashboard → **Email Services** → Add Service
- Connect your Gmail/Outlook
- Copy the **Service ID**

### Step 3: Create Email Template
- Dashboard → **Email Templates** → Create New
- Use these template variables:
  ```
  {{name}}       — Sender's name
  {{email}}      — Sender's email
  {{message}}    — The message
  {{time}}       — Submission timestamp
  ```
- Copy the **Template ID**

### Step 4: Get Public Key
- Account → **API Keys** → Copy **Public Key**

### Step 5: Update script.js

```javascript
// Initialize with your credentials
emailjs.init({
    publicKey: 'YOUR_PUBLIC_KEY',
    blockHeadless: true,
    limitRate: { throttle: 10000 }
});

emailjs.send(
    'YOUR_SERVICE_ID',
    'YOUR_TEMPLATE_ID',
    { /* form data */ }
);
```

### Step 6: Secure Your Account ⚠️

> **Important:** EmailJS Public Key is **meant to be public**. It's safe to expose in client-side code.

**Protect your account instead:**
1. Go to **Account → Security**
2. Add `https://arunpandi17.github.io` to **Allow origin** (domain whitelist)
3. Enable **reCAPTCHA** (recommended)
4. Enable **blockHeadless** in SDK options

## 🔒 Security Notes

- ✅ **EmailJS Public Key** is designed to be exposed — safe in client code
- ✅ **Domain whitelist** in EmailJS dashboard protects from abuse
- ✅ **`blockHeadless: true`** blocks automated bots
- ✅ **`limitRate`** prevents spam
- ❌ **Never commit** real API secrets, DB passwords, or private tokens
- ❌ **Never include** `.env` files with sensitive data in a static site
